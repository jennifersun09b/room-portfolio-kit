# Hillside Hearth Cottage: real-world references

Room id: `hearth_cottage`. This is a themed room (kit v4). It is a timber-and-plaster cottage kitchen on a
mossy hillside, with a hearth, a loft bed, laundry blowing on a line and tall meadow grass outside. It evokes the
*feeling* of hand-painted countryside animation, with warm sun, cosy clutter and nature growing into the house.
All designs are original (see "IP-safety" below).

Every piece below is modelled on a real object at its real size. Product names appear only here and in the template's
`REFERENCES` comment, never in the scene.

## Notes on scale
- Counter 90 cm, table 76 cm, chair and window-seat seats 45–48 cm, door 2.03 m, lantern about 0.75 m above the
  table. These all match SPEC section 7.
- The cottage stands on a 16 cm rubble-stone plinth, so `FLOOR_Z = 0.16`. Slots sit on the floor boards.

## IP-safety (what was deliberately avoided)
The room only evokes a broad genre: the hand-painted countryside / cottagecore feeling of warm sun, cosy clutter and
nature growing into the house. Everything in it is an ordinary cottage object or an original design. These are the rules
we followed (described generically on purpose, so this file does not itself list any franchise's designs):
- **No franchise, studio, film, person or character names** anywhere: scene, object names, comments, file names,
  theme names or tags. The file is `hearth_cottage` and the themes are `summer_afternoon` and `rainy_lantern`.
- **No characters, creatures or spirits, and no lookalikes.** There are no fantasy creatures, sprites, faces in the
  fire or anthropomorphic objects. The only animal is a generic ginger tabby asleep in a basket.
- **No story-specific props or scenes.** No iconic food, vehicle, broom, magic object, building silhouette or
  machine from any film or book. The shelf ornaments are generic felt toadstools and a small wooden hedgehog.
- **Generic architecture.** The tree is an ordinary old broadleaf tree with roots, with no shrine, rope or gate. The
  door is a rectangular stable door and the round window is a common real-world oeil-de-boeuf; nothing is shaped after
  a famous fictional dwelling.
- **No copied artwork.** No background painting, colour script, skyline or map from any film. The clouds, hills and
  meadow are simple procedural shapes, and shading uses the kit's own procedural `surface()` materials.
- **Text** is only the user's own hooks (the name board) and plain word labels on jars ("jam", "honey", "plums").
  No logos, brands, quotes or crests.
